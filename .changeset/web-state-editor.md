Add the state diagram visual editor: states with display names and descriptions, start and end [*], choice, fork and join, composite states with concurrent regions (nest, move in and out, wrap, ungroup), notes, transitions with labels (self-loops and parallels drawn apart), direction, a floating inspector, a toolbar to click or drag every item onto the canvas, auto layout, connecting by dragging a handle (or dropping on empty canvas for a new state), inline renaming, delete and keyboard nudges. Every edit is one labelled undo step, and the selection is shared with the rest of the app with Mermaid ids, so Split mirrors it.
