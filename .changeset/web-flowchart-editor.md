Add the flowchart visual editor: all 53 shapes, icon and image nodes, links with labels, line styles and ends, groups, direction, multi-select, delete, duplicate (⌘D), keyboard nudges, connecting by dragging a handle (or dropping on empty canvas for a new node), inline renaming, a floating inspector, and a library with Shapes and Icons opened from the canvas toolbar. Every edit is one labelled undo step, and the selection is shared with the rest of the app.
